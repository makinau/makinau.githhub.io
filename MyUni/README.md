# MyUni

Espai personal per organitzar tasques i projectes universitaris.

## Com començar

Obre `index.html` en un navegador. No cal instal·lar dependències ni executar cap servidor.

## Funcionalitats

- Crea tasques amb projecte, data límit i prioritat.
- Marca les tasques com a completades o elimina-les.
- Filtra per avui, pendents, completades o projecte i cerca per text.
- Crea, edita i elimina projectes; les tasques es conserven si elimines un projecte.
- Les dades es desen localment al navegador i no s’envien enlloc.
